1. **Illustrations = React elements, not strings.** The logic class runs in `new Function("DCLogic","StreamableLogic","React", …)` scope, and the runtime's `walkText` renders a `{{ }}` hole as real DOM iff its value is a React element (a string renders escaped inside `<span class="sc-interp">`).
